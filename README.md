# FinSight Customer Analytics

An analytical assessment exploring customer savings,
loan risk, digital engagement and product holdings.

## Project status

Project setup completed. Data cleaning and analysis are in progress.

## Objectives

1. Identify and document data-quality issues.
2. Analyse savings and customer behaviour.
3. Examine loan penetration and repayment risk.
4. Compare digital engagement and product holdings.
5. Define five business KPIs.
6. Present recommendations and analytical limitations.

## Planned tools

- Python
- Pandas
- Jupyter Notebook
- Power BI
- PowerPoint

## Project structure

- data/: Local source data, excluded from Git.
- notebooks/: Data cleaning and analysis.
- reports/: Presentation and summary outputs.
- dashboard/: Dashboard deliverables.

## Data confidentiality

The original dataset is confidential and is not included
in this repository. Customer names, NIC numbers and
customer-level financial records must not be committed.

## Analysis approach

Cleaning decisions, assumptions and limitations will be
documented before drawing business conclusions.
